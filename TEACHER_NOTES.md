# BYNEST — Teacher Notes

The project contains two editions:

1. **Browser edition:** `index.html` runs on GitHub Pages. Its lobby and global leaderboard use Firebase Authentication (anonymous) and Firebase Realtime Database.
2. **Java edition:** `java/SplitSecondMathArena.java` is the Java 17 desktop source and `download/BYNEST.jar` is the compiled desktop game.

The browser game keeps the original Split Second structure: 5 difficulty families × 3 tiers, 10 questions per round, 10-second question timers, multiple-choice answers, scoring, lobbies, and results.
