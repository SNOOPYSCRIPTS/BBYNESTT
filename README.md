# BYNEST — Neon Split Second Math Arena

A browser-playable BYNEST math game for GitHub Pages with a black/neon-green UI, multiplayer lobbies, Firebase Realtime Database syncing, and global records.

## Web version

Open `index.html` in the GitHub Pages site.

## Multiplayer

- Public and private lobbies
- 5-character room codes
- Cross-device room discovery and joining
- Shared question set for the lobby
- Live player scoreboard
- Firebase Realtime Database synchronization

## Global records

The Global Records screen shows **Top 1–3** only. Entries are ranked by:
1. Most correct answers
2. Fastest total time as the tie-breaker

A player's best result is used when choosing the top 3 display records.

## Java version

The `java/` folder contains the Java desktop source and `download/BYNEST.jar` contains the Java build.
